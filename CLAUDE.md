# Writing style

Write all text plainly and directly. This applies to chat replies, UI copy, docs, comments, and commit messages.

- Say what something is or what to do. Don't use lofty, poetic, or evocative language.
- Avoid abstract or metaphorical phrasing (for example "creative attention lasts longer inside real connection", "refuse the pull", "open loops", "park it").
- Prefer short sentences and everyday words.
- Don't add inspirational framing or filler.
